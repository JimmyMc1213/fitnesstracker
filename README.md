# New You AI

## Apps

| Package | Path | Description |
|---------|------|-------------|
| `@newyouai/pwa` | `apps/pwa` | Vite React PWA (product app) |

## Commands (repo root)

```bash
npm ci
npm run dev:pwa
npm run build
npm run test
npm run test:e2e
npm run typecheck
```
